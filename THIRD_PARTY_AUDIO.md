# Third-party audio

All bundled audio is downloaded from Wikimedia Commons. Each source page marks the recording as
**Public domain**, with attribution not required. The app still keeps the source metadata here for
traceability. The bundled MP3 files were derived from Wikimedia's generated transcodes and edited
with a 1.5-second equal-power crossfade to create smoother loop boundaries.
